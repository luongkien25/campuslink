3. **Quan sát tương quan & giới hạn (chưa khẳng định nhân quả):**
   - Trong log Nginx, `urt ≈ rt` (lệch tối đa ~1 ms), cho thấy thời gian xử lý phía server nằm ở đoạn sau Nginx (VIP → app VM → DB VM).
